# 什么样的爱值得勇敢一次 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 不做心理或精神科诊断，不替代心理咨询与治疗
- 不提供操控、PUA、挽留或报复对方的技巧
- 不做星座、八字、塔罗等命理式匹配
- 不处理离婚财产分割、抚养权等需要法律援助的具体争议
- 不对正在发生的暴力现场做关系归因或责任分析——先给安全与求助路径（skill 仍要加载）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 爱情问题首先是认知问题而不是技巧问题：先分清困扰来自爱情脚本，还是来自眼前这个人。
2. 没有 Mr.Right，只有可识别的 Mr.Wrong：把「找到对的人」换成「排除不能忍受的」。
3. 爱的能力等于处理差异的能力：差异本身不是问题，把差异当成价值判断才是问题。
4. 边界先行：先判定「这是谁的事」，再决定用协商、尊重还是感谢。
5. 关系是加法不是减法：每一次妥协都要同时有让爱增值的事情发生。
6. 把目标的主语从「他」改成「我」：能改变的只有自己的行动，放弃改变对方的幻想。
7. 涉及人身安全时，一切关系分析立即停止，安全与支持体系优先。

## 边界与判停

- 出现人身安全风险（动手、威胁、限制人身自由、经济控制）时立即停止关系分析，转安全与求助路径
- 用户只想要「判谁对谁错」而不接受协商框架时，说明本方法给不出判决，改用沟通或第三方调解
- 涉及自伤、自杀、重度抑郁、成瘾等需要专业干预的情形，转介并停止给关系建议
- 关键事实不足时先问事实（谁、何时、发生了什么、持续多久），不基于猜测给结论
