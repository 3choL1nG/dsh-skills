# 关系危机：日久生倦、出轨、恐婚与体面分手

> slug: crisis-navigation ｜ 重要性: high ｜ 覆盖任务: task-26, task-28, task-29, task-30
> 一句话: 危机发生后先过安全闸门，再按「暂停 → 梳理 → 分流」产出书面决定；凡以「他会更爱我 / 他会改」为主语的行动判为不可执行，退回改写成以「我」开头。

## R — 原文依据

## I — 方法骨架

解决什么问题：关系从「冲突」升级为「危机」（日久生倦、出轨、恐婚、需要分手）后，当事人只剩忍受与决裂两个选项、且在情绪峰值被要求立刻决定。

输入：事件类型与时间线｜双方当前状态（是否摊牌、是否分居、是否仍在联系第三者）｜非感情联结清单（经济、人情、事业、子女）｜**安全筛查（控制、威胁、暴力、经济剥夺、社交封锁）**｜恐婚另需双方的担忧原话。

判据与步骤：先过安全闸门（命中即改道，不做协商）→ 做类型归判（出轨：累积结果型 / 特殊情况型；恐婚：对人性不确定型 / 对婚姻本身恐惧型；倦怠且出现新对象：A / B 比较型）→ 出轨走「暂停 1–3 个月 → 梳理非感情联结 → 在分手与重建间分流」，重建走四步（重建信任靠行动 / 克制再克制 / 放过对方 / 创造新的共同记忆）→ 恐婚走「事实沟通 → 婚姻新脚本 → 止损预案」，或走「放弃的勇气」→ 分手走主动方四条礼仪与被动方两步，并设时间限度 → 倦怠走自我成长三步（打开社交圈 / 找新爱好 / 追问婚姻对我的意义），启动时二选一（走最难的一步，或从最容易的开始）。

输出：一份带截止日的暂停期梳理表 + 一份分流决定书（含最坏后果承受度）+ 所选分支的可核验动作清单。

边界：目标是「产出可核验的决定与下一步动作」，不承诺关系结果（作者原话：危机永远没有完美的解决方案）；权力悬殊（一方占有绝对经济优势）或存在暴力时，本流程的协商前提不成立。

## A1 — 案例

**c38 爱丽与李智：出轨后的重建**（`case_kind`：作者转述个案）
结婚 7 年，孩子出生后爱丽太忙、没像恋爱时那样关注李智；李智生日那天爱丽去单位想给惊喜，发现日程表上写着「和D吃饭」，追问后李智承认与董小姐有婚外性行为。此后一年多拉扯，李智认为道歉就够了、最后表态「你要么相信我，要么我们就离婚吧」，两人走到即将离婚的地步。作者给的处置是：①先按暂停键 1–3 个月，梳理在一起与分开的理由；②梳理感情之外的联结（经济、人情、事业）；③在分手与重建之间分流。因为发现婚姻出问题也缘于两人没重视沟通和仪式感，又有尊敬的老人和可爱的孩子，最终决定重建。重建四步落地：李智停止与「小三」私下联系、汇报日程、允许查看手机，并积极加入家务育儿；爱丽在愤怒半年、把问题理清后再没提过这件事，把「出轨」视为婚姻中的敏感词，吵架也不用这个词；第三步放过对方；第四步每个周末陪孩子出去玩、节假日一起规划旅行、定期拜访双方父母、纪念日做有仪式感的事，慢慢美好的回忆冲淡了过去的痛心。**原书结论：「爱丽和李智就是这样一对夫妻」（L1542），最终重新成为幸福夫妻。** 这是全书唯一走完「暂停键 → 分流 → 重建四步」的完整长案例，也是重建分支的主证。

## A2 — 触发场景与语言信号

**场景 1：刚发现出轨，被要求立刻决定去留**
中文：「我翻到他手机了」「他说只是吃饭没上床」「我想马上离，可是房子和贷款怎么办」「我一看到他刷手机就发抖」「我到底该不该离」
英文："I found messages on his phone." "He says nothing happened." "I can't stop checking his location." "I want to leave but I can't afford to."

**场景 2：日久生倦，无话、无性、以孩子或惯性维系**
中文：「我们一天说不到十句话」「他说对我一点感觉也没有了」「就这样过吧，还能怎么办」「等孩子高考完再说」「我们像室友」
英文："We're just roommates now." "There's nothing left to talk about." "I don't know if I still love him."

**场景 3：一谈结婚就吵（恐婚）**
中文：「一说到结婚他就岔开话题」「我不是不爱你，我就是怕」「结了再离不是更失败吗」「为了他，值得我走进那个婚姻制度吗」「一想到要当儿媳妇就头大」
英文："Every time marriage comes up we fight." "I'm not ready, but I don't know why." "It's not you, it's marriage."

**场景 4：要提分手，或刚被分手**
中文：「我想提分手，但不想撕破脸」「他一直打电话来，我该接吗」「是不是我不够好」「分手是不是说明我这段感情失败了」
英文："How do I end this without destroying him?" "She keeps calling me." "Maybe I'm the problem."

**场景 5：倦怠期出现新对象**
中文：「我遇到了一个让我重新有感觉的人」「要是选了他，他以后会不会也变成现在这样」「我在两个人之间选不出来」
英文："I met someone who makes me feel alive again." "What if he turns into the same person in five years?"

**与相邻能力卡的区分**
出现控制、威胁、暴力、经济剥夺、社交封锁 → 用 `safety-exit`（安全分支优先，本卡时序作废）。只是「当下这一场冲突怎么谈」→ 用 `conflict-protocol`。关系没到危机、想经营长期关系（加法关系、仪式感、三大错误方向）→ 用 `long-term-maintenance`。争的是房贷、AA、三抽屉 → 用 `boundary-three-kinds`。还没进入关系、在筛底线 → 用 `mr-wrong-baseline`。要在结婚前逐条对答案 → 用 `marriage-decision`。

## E — 可执行步骤

**必需输入**（缺任何一项必须先问用户，尤其第 4 项）：
1. 事件类型与时间线（发生了什么、什么时候知道的、持续多久）；
2. 双方当前状态（是否已摊牌、是否分居、是否仍在联系第三者、是否已有第三方介入）；
3. 非感情联结清单（经济 / 人情 / 事业 / 子女，逐条列事实）；
4. **安全筛查**：有无控制（查手机、限制社交、经济克扣）、威胁、动手、孤立；**未完成筛查前不得进入协商流程**；
5. 恐婚情形另需：双方各自的担忧原话，以及「是否已就结不结正面谈过」。

**交付物与完成标准**（可检验）：
- 《暂停期梳理表》：三栏（在一起的理由 / 分开的理由 / 非感情联结），每栏 ≥3 条且每条能指认来源事实；
- 《分流决定书》：选择（分手 / 重建 / 暂缓）+ 依据（引用上表条目与类型归判）+ 最坏后果与承受度；
- 若重建：《重建四步清单》，第 1 步必须是可核验行动（停止私下联系、日程可见、允许查岗），**口头道歉不计入**；
- 若分手：《分手礼仪检查表》（主动方 4 条 / 被动方 2 条）+ 时间限度（具体到次数或日期）；
- 若恐婚：类型归判 + 基于事实的担忧清单 + 婚姻新脚本条目 ≥3 条 + 止损预案；
- 若倦怠：自我成长三步行动清单（每步至少 1 个能在一周内启动的动作）+ 主语改写表（每条目标改写成以「我」开头）。

**步骤**：

0. **安全闸门（先于一切）**：出现控制 / 威胁 / 暴力 / 经济剥夺 / 社交封锁 → 立即停手，转 `safety-exit`，不再往下走。
1. **类型归判**：出轨——长期关系问题由小积大、出轨是最后结果 → **累积结果型**（要同时处理关系本身的问题）；夫妻关系本身没出问题、仅因特殊情况出轨 → **特殊情况型**。恐婚——怀疑自己/伴侣/双方能否维持长期关系、怕失去独立性 → **对人性不确定型**；怕的是婚后生活、角色（妻子/妈妈/儿媳妇）、生育与复杂关系 → **对婚姻本身恐惧型**。倦怠且出现新对象 → **A/B 比较型**（A 给安全感，B 给心动）。判据：归型决定后续重点与是否值得重建，不归型就梳理不清。
2. **出轨路径：按暂停键 1–3 个月**，设书面或日历截止日。谁暂停什么：双方暂停「去留的最终决定」；被出轨方暂停一切对外宣告（不通知双方父母、不发朋友圈、不去找第三者对峙、不拉黑）；出轨方暂停与第三者的任何私下联系，且只记行动、不作自证式表态。期间要做：各自写「在一起的理由 / 分开的理由」；列非感情联结三栏并逐条标「可解除 / 需谈判 / 不可解除」；复查安全筛查；恢复基本生活节律。期间不做：不在情绪峰值做去留决定；不去确认第三者是否比自己优秀、不发动「大战小三」；不用出轨往事作日常争吵筹码；不接受「我已经道歉了」作为唯一行动；不让双方父母或共同朋友进入裁决位置。（暂停期的「做/不做」清单是本卡对 L1514–L1515 的执行化展开，原书只写了「重新去梳理这段关系的意义」。）
   **判停**：对方拒绝暂停、持续施压（逼当场签字离婚，或逼当场无条件原谅）→ 暂停键失效 = 分流前提不成立，改为先做自保准备（证据固定、居住与现金流方案），再进分流。
3. **梳理非感情联结**：经济、人情、事业、子女四类逐条列事实并标注处置；这一步常常改变「能不能离」的答案（作者：它比我们想象的更复杂）。
4. **分流**：在「分手 / 重建 / 暂缓」之间选一个，并写出最坏后果与承受度。责任划分先行：**主要责任在出轨方**（契约关系不能单方解除），不把主要精力用于与第三者比较。
   **判停**：对方有性瘾、或出轨方占有绝对经济优势并以财产相威胁 → 跳出重建四步，转为「如何让自己在能力与经济上有话语权」，此时不再协商。
5. **分支执行**：
   - 重建四步：①重建信任（出轨方以行动加固「墙」：停止与第三者联系、汇报日程、允许查看手机；被出轨方平衡约束与自由）；②克制再克制（不把往事当控制对方的筹码，出轨方不用「我已经道歉了」反击）；③放过对方（未必要宽恕，但一定要放过）；④创造新的共同记忆（更多相处时间、仪式感）。**判停**：第 1 步两周内没有任何可核验行动 → 重建路径判 fail，退回第 4 步。
   - 分手：主动方四条——当面告知、承担一定责任并真诚分析困境、主动处理双方父母与朋友的关系、允许对方纠缠但约定底线与时限；被动方两步——避免道德判断、重建自我（分手常只意味着现阶段不合适）；时间限度要可数（例：再回 3 次电话后不再回应）。
   - 恐婚（对婚姻本身恐惧型）：先深度自我对话看清自我需求 → 基于事实坦诚沟通（把「婚后哪些事我可能做不到」讲出来；基于事实的沟通不伤感情）→ 建构婚姻新脚本（不必扮演好妻子、好儿媳妇）→ 保留及时止损预案。
   - 恐婚（对人性不确定型）：理清底线（什么情况下可以走进婚姻）→ 评估自己对关系变化的接受度 → 反思并检验「男人有钱就变坏」这类假设。**判停**：若实为「不爱这个人但没有契机说不」→ 走的是放弃的勇气，不是婚姻新脚本；此时转 `mr-wrong-baseline` 复核适配性。
   - 日久生倦：先否决两条建议——不要用成本收益表决定去留（真正算得清的只有经济账，之后整个生活的改变算不清），不要为换取对方更爱而改造自己（改变生效的前提是对方接受，等于把主动权交出去）；再做主语改写（把「他会不会更爱我」改成「我想要什么样的生活、什么样的亲密关系、哪些是必须通过他才能获得的」）；然后走自我成长三步（打开社交圈 / 找新爱好 / 追问婚姻对我来说意味着什么），启动时二选一（走目前最需要的那一步，或从最容易、不影响他人利益的一步开始）。**判停**：对方持续忽视、贬低而非沟通 → 先走「说明限度 → 敞开心扉 → 必要时暂停关系或分手」。
6. **时间盒与稳态检查**：暂停期不超过 3 个月；到期必须产出分流决定。到期无任何梳理动作 = 停摆，改为先动一个最小变量（倦怠路径的第二条启动路径），不要继续空转。

## B — 边界与反场景

**不适用场景**
- 存在控制、威胁、暴力、经济剥夺、社交封锁 → 用 `safety-exit`；本卡的「协商式时序」在暴力关系中会被施害方武器化。
- 关系仍在冲突层（单次争执、三类冲突未归判）→ 用 `conflict-protocol`，不要用危机流程处理一场吵架。
- 尚未进入关系或正在筛底线、对答案 → 用 `mr-wrong-baseline` 或 `marriage-decision`。
- 一方已明确且持续拒绝任何沟通，或已进入诉讼程序 → 本卡时序失效，只剩决策与执行。
- 涉及财产分割、抚养权、人身安全保护令等法律后果 → 本卡只做决策与沟通，**不替代法律意见**（此点为提取器补充观察，非原书内容，原文见 counter-examples.md 文末）。

**作者警告的失败模式**
- **x34 出轨后的常见错误处置：立刻决策 + 大战小三**——情绪波动期做出的决策往往不合理；把火力对准第三者会回避经济、人情、事业等更复杂的联结与自身需求。纠正：先按暂停键 1–3 个月 → 梳理非感情联结 → 分流 → 重建则走四步；主要责任归出轨方。
- **x35 把恐婚归因于身边的坏榜样与媒体渲染**——用「我见过的婚姻都不幸福」和影视剧解释恐婚，实际是抽样偏差与媒体选择性的产物，结果是「根本不知道自己在恐慌什么，就匆匆分手了」。纠正：先定位恐婚类型再分流，用基于事实的沟通替代道德批判。
- **x31 家暴迷思一：受害者有错论**——这条的处置归 `safety-exit`；本卡只把它当作一条红线：不得用受害者的人格或行为解释暴力的反复发生（本卡不做家暴处置）。

**作者的盲点与时代局限**
- **「把主动权拿在自己手上」的双面性**：该主张在 9、17、26、27、29 节反复出现，把关系改善的责任主要放在个体（且常被期待为「更能主动探索」的女性）身上，对制度性不公（家务劳动未定价、家暴执法成本、离婚经济劣势）以「让自己更有实力」收束（BOOK_OVERVIEW §3.2）。本卡在出轨重建与「绝对经济优势」分流处会正面撞上这条：当出轨方占有绝对经济优势时，暂停—梳理—分流的协商前提已经不成立，本卡只能交付「能力与话语权」方向，不能交付决策。
- **时代与样本局限**：本卡依赖的关键统计为 2015–2018 年口径（潘绥铭 2015 年出轨率、2013–2018 年结婚率五连降），**口径可能过时，不得作为前置事实断言**，本卡也不以其为任何结论的前提；全书个案偏一二线城市中产（BOOK_OVERVIEW §3.1）。此外「暂停 1–3 个月」隐含稳定收入、可独立居住、有可倾诉对象三个前提，对低收入、流动人口、无独立住所者可能不成立——此时暂停期应缩短并优先解决居住与现金流。
