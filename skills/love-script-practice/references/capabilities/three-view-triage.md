# 三观一致性与四题型分流

> slug: three-view-triage ｜ 重要性: high ｜ 覆盖任务: task-14（并由 task-06 交叉引用容量结论）
> 一句话: 把「三观不合」逐题归入底线题／关键题／差异题／开放题；底线题不一致且反复冲突 → 走结构性调整（继续或分开），非核心不一致 → 只设行为边界并要求对方答案。

## R — 原文依据

> "如果你们在同一类事情上反复冲突，很可能就说明你们的三观不一致。对此，你有两个选择。" —— §14 价值底线：什么是「三观一致」，L794

> "第一，重新审视两个人的三观，判断是不是核心价值观，如果是的话，就需要进行结构性的调整，反思两个人有没有办法在一起生活。换句话说，是不是得考虑离婚或分手。" —— §14，L795（第二选择见 L796：非核心价值观则「确立行为边界，确定是你、我，还是我们的事」；后果条款在 L797）

> "底线题涉及“我们”的重要事宜，这些问题就是核心的价值观问题，最好在初期关系中双方能达成一致，这样在长期关系中更能维持，当然，有些问题的答案在未来可能会发生变化。" —— §14，L800（L801 关键题＝求同存异、L802 差异题＝长期更有助于亲密关系深入、L803 开放题＝一致与否不重要；使用判据在 L804）

> "我们在《令人心动的cp》这款爱情桌游中，专门设计了四种类型的题目：底线题、关键题、差异题和开放题。" —— §07 Mr.Right，L452（同一框架的首次引入，L453 补「底线一致则未来需结构性调整的可能性更小」）

辅助依据（不作逐字引用）：三观分层与金钱观落地在 L773–L776；「三观并非一成不变，它是会慢慢改变的」在 L786；「你也可以自己来界定哪些是你的核心价值观，是你不可动摇的底线」在 L805；「你的底线越多，彼此协商的空间越小」跨 L805–L806（原文此处换行断开）。三观是「努力靠近」而非「筛选到位」的说法在 L808。

## I — 方法骨架

解决什么问题：终止「三观不合却不知道该谈还是该分」的内耗——先判性质，再选动作。

输入：**同一类事上的反复冲突记录**（≥2 次，附至少一个具体事件）＋一段可枚举的议题清单（4–8 条具体题目，不是「钱的问题」而是「收入是否合并／超过多少要报备」）＋**双方对每条题目的答案**＋**用户自己认的底线**。

判据链：
1. 触发：只在「同一类事反复冲突」时启动；单次事件不该用本卡。
2. 落地：世界观 → 人生观 → 价值观 → 金钱观，把「他不爱我」改写成可讨论的题目。
3. 归判：每一条题目归入四型之一——底线题（涉及「我们」的重要事宜，核心价值，初期须一致）／关键题（重要但可协商，求同存异）／差异题（存在差异但不一定影响关系，长期「不同」反而有利）／开放题（拓展边界，一致与否不重要）。
4. 分流：命中的底线题且双方答案不一致 → 结构性调整（要不要继续）；非核心不一致 → 设行为边界（分清你／我／我们）并承担选择的后果。
5. 容量：每多认一条底线，协商空间就缩小一分；输出末尾要交代余量。

输出：一张逐题归判表（议题｜题型｜我方答案｜对方答案｜是否核心｜处置｜是谁的事）＋一条明确的二选一或三选一结论。

边界：题型来自作者自研桌游，书内无外部效度证据；「重要事宜」与「反复」都没有量化门槛；归判权在用户，不在这张卡。

## A1 — 案例

1. **婚戒：品牌还是带钻** —— `case_kind`：作者转述个案（作者的好朋友与丈夫，L777）。
   女方看中某品牌的设计感，男方认为牌子不重要、重要的是带钻，最后买了钻戒；女方觉得「他不够尊重我、没听取我的心声」，甚至想「这个婚不结也罢」。作者分别问了两人：男方坚持钻戒是希望婚姻像钻戒一样不贬值，女方认为婚戒是向他人展示身份的符号、要一直佩戴。作者的判断是——两人都想把自己认为美好的东西送给对方，跟爱不爱、尊不尊重没关系，**核心问题是两人对金钱的价值观不同**。
   用途：示范第 2 步「把价值判断改写成价值观题目」。**原书未说明这场分歧具体如何收场**（只交代两人「一直很恩爱」）。

2. **孝顺观分歧** —— `case_kind`：作者亲历（L782）。
   作者认为孝顺就是顺从爸妈、开心就好；先生认为应引导父母过更积极的生活（她父亲抽烟很凶，先生主张帮他戒）。两人会为此争论，但能互相理解和宽容，最后的处置是：他可以去影响他自己的爸妈，她就顺从她的爸妈。作者用它说明非核心价值观的冲突解法是**确立行为边界、区分是你、我、还是我们的事**（L796 直接回指此例）。
   用途：示范第 4 步的「非核心 → 行为边界」分支。

3. **登记当天发现未婚夫刷爆信用卡** —— `case_kind`：作者转述个案（微博群群友，L1264–L1266）。
   群友在登记前一天发现未婚夫信用卡全刷爆，在群里问「明天还要不要去登记」。作者问她「经济安全对你来说是不是底线问题」，她说是。众人建议调查清楚再结；结果发现未婚夫还做了大量担保、欠了很多债，婚没有结——「她和未婚夫对经济底线有截然不同的理解」。
   用途：示范第 4 步的「底线题不一致 → 结构性调整」。注意该案例同时是 §23「底线冲突」的主证（`task_ids` 含 task-23），本卡与冲突协议卡共用，不独占。

## A2 — 触发场景与语言信号

1. **反复为同一类事吵，开始怀疑是不是三观**
   中文：「我们总为同一件事吵」「这件事说了不下十次了」「说来说去还是这个问题」「是不是我们三观不合」
   英文：we keep having the same fight / it's always this one issue / we go in circles / are we just not compatible
2. **想知道这算底线还是可以磨合**
   中文：「这算底线问题吗」「这是三观不合还是可以协调」「是我太较真还是真的不合适」「他这样算不算触到我的底线」
   英文：is this a dealbreaker or just a difference / is this a values clash / am I overreacting / where's the line
3. **该改还是该分（结构性调整的请求）**
   中文：「三观不合要不要分」「该为他改还是该分开」「是不是得考虑离婚」「我该不该继续」
   英文：should we break up over this / is there a future here / do we want different things / should I stay
4. **钱与共同财产上的观念冲突**
   中文：「钱的问题上我们观念完全不同」「他觉得钱要放一起才叫一家人」「他给家里转钱不跟我说」「AA 到底行不行」
   英文：we fight about money / he transferred money without telling me / joint account or separate / how do we split
5. **筛选期想知道该谈清什么（含容量焦虑）**
   中文：「恋爱初期要谈清楚哪些事」「什么算底线题、什么算差异题」「我的底线是不是定太多了」
   英文：what should we agree on early / how many dealbreakers is too many / is my list too long

**与相邻能力卡的区分**：只谈**当下这一场**冲突怎么开口（说事实／感受／需求）→ conflict-protocol；困扰来自「他怎么可以这样」背后的预设与价值判断，尚未到判核心与否 → difference-value-judgment；用户真正的卡点是「我说不出自己的底线」→ mr-wrong-baseline（先做三条底线与容量）；出现控制、威胁、暴力或经济控制 → safety-exit（本卡的「结构性调整」不是安全危机的处置流程）；问题是日久生倦、出轨、恐婚这类长期去留决策 → crisis-navigation。

## E — 可执行步骤

**必需输入**（缺任一项就先问，不要代填）：
1. 同一类事的**反复**冲突记录：至少 2 次，并给出最近一次的具体事件（谁、何时、做了什么、说了什么）。
2. 议题清单：由 agent 陪着把模糊的「我们三观不合」拆成 4–8 条**具体题目**（「钱的问题」不算，要拆到「单笔支出超过多少须事先告知」）。
3. 双方对每条题目的答案：至少要有用户自己那一栏；对方那一栏缺就标注「未取得」，不要在表里替对方写。
4. 用户自己认的底线条目（用户说不出来 → 停，转 mr-wrong-baseline）。

**交付物与完成标准**：一张逐题归判表（议题｜题型｜我方答案｜对方答案｜是否核心价值观｜处置｜是谁的事）＋一条明确结论（协商／结构性调整／分开，三选一或二选一，不许写成「多沟通」）＋一句容量说明（已认几条底线、还剩多少协商空间）。完成标准：每条议题都有唯一题型、唯一处置；底线题不一致时结论里必须出现「结构性调整」字样或明确的分开判断。

**步骤**：
1. **核触发条件**（L794）：问「这类事发生过几次」。≥2 次且同属一类 → 继续；只发生过一次 → **停手**，转 conflict-protocol 或 difference-value-judgment。
2. **三观落地**（L773–L776，p46）：把用户的抱怨句改写成价值观题目。判据：改写后的句子必须两句都成立且都不含人品评价（能写成「你要 A，他要 B」才算完）。产出表头一栏。
3. **枚举议题**：与用户一起把议题拆到可分别回答的粒度，每条写成疑问句。
4. **逐题归判**（L800–L803，p51）：按四类判据填表。判据不清时问两个问题——① 这涉及「我们」的重要事宜吗？② 如果对方一辈子都是这个答案，你能接受吗？两问都指向「重要＋不能接受」才归底线题。**归判权归用户**（L805），agent 只解释判据。
5. **核一致性**（L804）：标出底线题与差异题上的一致性。注意这只是资源提示，不是「能长久」的预测。
6. **分流与边界**：底线题不一致 → 走 L795 结构性调整（先就那一条做一次正式协商；仍不一致则评估要不要继续）并声明后果自负（L797）；非核心不一致 → 走 L796 行为边界，明确「是谁的事」，把可检验的方案写下来（如各自账户＋共同账户按比例注入）。
7. **容量交代**（L805–L806，p49）：数一遍用户已认的底线条数，说明每加一条会挤掉多少协商空间。

**判停点**：
- 对方拒绝回答或拒绝协商，而命中的是底线题 → 停止协商，转结构性调整判断，并说明「坚决不让步、对方决定分开」是成年人的后果（L797）。
- 出现经济控制（扣工资卡、查账惩罚、限制人身或社交）、威胁、暴力 → **立即停手**，转 safety-exit。
- 用户说不出自己的底线／核心价值观 → 停在本卡第 3 步，转 mr-wrong-baseline，不得由 agent 替用户认定「这是你的底线」。
- 走完只剩「再靠近一点、慢慢磨合」这一句（援引 L808）→ 判为本卡失效，必须回到 L795／L796 两条分支之一落地。
- 结论涉及离婚财产、抚养权等法律处置 → 超出本卡，转专业法律渠道。

## B — 边界与反场景

**不适用场景**：
1. **单次冲突**：不满足 L794 的「反复」触发条件，此时谈题型是过度诊断。
2. **尚未共同生活的初期关系**：底线题的答案还没被现实检验，容易把想象或理想当底线（原文只说「最好在初期关系中双方能达成一致」，L800，是「最好」不是「必须」）。
3. **一方处于控制型关系，或存在威胁、暴力、经济控制**：本卡的协商与边界流程不适用，必须先走安全路径。
4. **用户要的是「判谁对谁错」或「帮我证明他三观有问题」**：本卡不产出道德判决，只产出归判与处置。
5. **需要法律处置的离婚财产、抚养权争议**：超出本卡能力。
6. **把本卡当筛选器**：本卡不预测「你们能不能长久」（L804 的「天作之合」是无样本口径的经验判断），只做当前议题的归判。

**作者警告的失败模式**：
- **x19 三观不一致时不做任何让步**（`task_ids: [task-14]`，对应 L793–L797）：在同一类事上反复冲突时只走一条路——坚持自己的答案，既不做结构性调整的决断，也不确立行为边界。它看起来像「守住底线」，实际是回避判断；后果是冲突反复发生、双方持续消耗。作者的纠偏方向：先用四题型判断性质，再决定协商还是结构判断；「你的底线越多，彼此协商的空间越小」（L805–L806）。
- 相邻失败模式（只在触发条件处引用，展开归各自能力卡）：把开放题当底线题吵，会把择偶空间压到极小（L803）；把底线题当差异题「长期看待」，会让结构性调整被无限延期（L808 的误用）。

**作者的盲点与时代局限**（取自 BOOK_OVERVIEW §3，本卡在此处会失效）：
- **§3.3 隐含的功能假设**：作者默认「能处理差异 ⇒ 关系变好」，未讨论差异处理能力被用于**更好地维持一段本应结束的关系**（沉没成本合理化）。本卡正落在风险点上：只要把底线题误判成差异题，或反复援引 L808「努力靠近」，就能让用户留在一条本该结束的关系里。缓解措施写进了 E 段第 6、7 步与判停点——底线题不一致时必须出现结构性调整分支，不许只给「再靠近一点」。
- **§3.1 样本与场景偏向中国城市中产／高知**：「重要事宜」的边界随阶层与文化而变（在需要承担家族义务的语境里，给原生家庭转钱可能不是越界而是义务）。因此本卡**不替用户认定哪条算底线题**——原文 L805 明确「你也可以自己来界定哪些是你的核心价值观」；agent 只解释判据、记录用户自己的答案，并在 B 段声明该判定的阶层与文化前提。
- 另需注意：作者对四题型的权威来自自研桌游（L452、L799），书内无外部效度证据；使用时不得把它当测量工具或预测工具。

## 相关能力

- composes-with: `mr-wrong-baseline`（底线提取与容量；本卡消费其结论，不重复其流程）、`boundary-three-kinds`（「你、我、我们」的判定器；本卡第 6 步的边界落地转由该卡细做）、`difference-value-judgment`（把冲突拆成预设与价值判断，是本卡第 2 步的前置）、`conflict-protocol`（当次冲突怎么谈）
- contrasts-with: `safety-exit`（命中控制与暴力即终止本卡）、`crisis-navigation`（长期去留决策，非议题归判）
