## 二、爱情的意义与关系类型

| 替代成本 | 作者的决策框架而非纯经济学定义：爱情的三大意义（自我的确定性、与他人建立联结、性欲望的升华）在功能上**都可以被替代**，所以「一个人也可以过得很好」是真的；但替代是有代价的，**核心句在 L214**——实际的替代成本比你想象中高很多，决策要把机会成本算进去。限定：作者同时给出趋势判断——物质匮乏解除后人们更追求纯粹关系，故爱情会越来越重要而非可有可无 | L214（三大意义 L205–L210） | love-script-audit |
| 自我确定性 | 借伊娃·易洛斯引入：日常生活中自我很抽象，人们用「有人爱我吗」来替代「我是否存在」这个问题。限定：自我无法自我确认，必须借外部回答才被看到；这是「爱情第一重意义（找到自我价值）」的理论底座 | L186 | love-script-audit |
| 镜中自我 | 借美国社会学家查尔斯·库利的概念并作者化：自我不是与生俱来的，而是在「想象他人如何看待我」的碰撞中才变得清晰可见。结论句：**是社会、文化、他人的目光等外在因素确定了你的自我价值** | L186 | love-script-audit |
| 纯粹关系 | 借吉登斯概念，作者作两面判断：一方面今天的爱情更接近纯粹关系（不靠制度、只靠关系本身维持）；另一方面它正是爱情变难的原因——爱情不得不处理自我与他者、感性与理性、激情与长久等冲突。**限定：作者全文未再给更严格的定义** | L24（L211 复用于趋势判断） | love-script-audit |

| 享乐型爱情* | 第一象限：有激情、很快乐，但「不一定」有成长。限定：作者态度明确正面——它是好的爱情模式、是好的开始，一见钟情通常属此类且浓度很高。核心挑战不是它本身有问题，而是当事人能否信任并享受快乐（理性往往紧随快乐而来把感性压下去） | L231 | relationship-health-scan |
| 互惠型爱情* | 第二象限：两人比较互补、互相促进，但不见得充满激情和快乐。三条限定：①互补不限于性格，硬件互补（收入、能力、资源）同样成立，「考虑物质条件不见得就损害了爱情」；②核心成长是「归属感的发展」；③年龄差较大的爱情往往属于这一类型 | L237 | relationship-health-scan |

| Mr.Wrong | 作者的核心方法论转向：把「追求幸福」的问题**改写成「预防风险」**的问题。Mr.Wrong＝对方身上你不能忍受、且通常很难磨合、最终会逼你对关系做结构性调整的问题。排除它的三个方法：①设定三条底线原则；②用每一段感情经历更新 Mr.Wrong 清单；③改问「我为何不能选择某个人」。附带三条行为底线 | L426（保守替代行 L428–L429） | mr-wrong-baseline, relationship-health-scan |
| 三条底线原则* | 三步筛选法：①拿一张纸列出所有在意的点，想到再也想不出为止；②想象对方都有这些缺点，划去相较而言能接受的；③强迫自己**只留三个**。两条硬限定：**底线是「你不能忍受的问题」，不是「你希望的特点」**（理想≠底线）；新底线出现时必须与旧底线比较，**只有更难接受才能替换**，否则不断往上码会让爱情越来越难 | L433 | mr-wrong-baseline |
| 0.5 理论* | 借台湾大学社会学教授孙中兴的容量估算：你的每一条底线相当于排除掉人群中一半的人，三条相乘只剩 12.5%，再加条件圈子会越来越小。用途：给「为什么只许留三条」提供量化理由，并放大「不要把理想当底线」。限定：该行属跨行断字的连续句，语义连贯，可逐字引用但须按完整句子粒度 | L436（跨行至 L437） | mr-wrong-baseline |
