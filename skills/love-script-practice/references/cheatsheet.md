# 决策规则速查 — 什么样的爱值得勇敢一次

| 能力 | 一句话规则 |
|---|---|
| 爱情脚本自查与双标检测 | 当用户说「总是遇不到合适的人」时，交付「我的爱情脚本」条目表 + 内部矛盾清单 + 取舍决定（无待定项）三样产物；每条双标按「要对方承担 X ⇒ 我是否承担对应 Y」判，Y 为空或与 X 互斥即命中。 |
| 关系健康度定位与消耗捆绑红线扫描 | 先按「快乐 × 成长」给当前关系定位并允许它变形态，再用四条标准逐条核对控制迹象——命中两条即停止「经营关系」建议、转安全排查。 |
| 婚姻决策：好处风险对照与十问清单 | 把"要不要结婚"降解为 四项好处×双面性对照 → 让渡权利清单 → 十问逐条答案对照 → 不可承受风险清单；十问中只要有任一条目**无法与对方讨论**，立即判停转"先解决能不能谈"，绝不替对方推测填答案。 |
| 底线筛选：排除 Mr.Wrong | 每条底线都要通过「不能忍受的问题 ≠ 希望的特点」这一检验，总数砍到 3 条（0.5³＝12.5% 量级），替换旧底线必须比旧的更难接受。 |
| 进入爱情的路径与主动策略 | 当用户说「脱不了单 / 我不敢主动」时，交付「途径选择表（含本周动作）+ 信号释放清单 + 第二空间设计 + 一句具体肯定话术 + 推进或放弃判定」；完成标准是每条结论都能指回一句用户原话、本周动作写得出时间与场合，且全部归因句的主语是「我」而不是缘分或年龄。 |
| 原生家庭与核心情结 | 当用户用「原生家庭」「一亲密就想逃」「我是不是有什么情结」解释自己的感情困境时，交付「家庭规范来源分析 + 需保留/更新的规范清单（每条注明来自谁的哪句话）+ 核心情结触发记录（一行一个具体事件）」；交付物里**不得出现替用户命名的情结标签**，也不得出现以父母为主语的定罪句——凡用户要求「确认父母不爱我 / 我该不该断亲 / 我到底是什么情结」，一律停在记录表并交回用户。 |
| 差异处理：价值判断拆解三步 | 把一次「他怎么可以这样」式冲突落成「事实／我的预设／他的预设／双方未说出口的价值判断」四栏拆解表，并产出双方各自 1–3 个敏感词的书面条约；拆出核心价值观冲突时必须停手转三观分流。 |
| 三观一致性与四题型分流 | 把「三观不合」逐题归入底线题／关键题／差异题／开放题；底线题不一致且反复冲突 → 走结构性调整（继续或分开），非核心不一致 → 只设行为边界并要求对方答案。 |
| 你我我们边界与权利责任利益一致原则 | 用「责任／权利／利益」三栏把一件具体争议判成「我们的事／你的事／我的事／我需要你帮助的事」——三栏同归一方判**尊重**、两人共担共果判**协商**、三栏在我而有你帮助则判**感谢**；判定结果须双方认可，且居住、收入、全职与否等结构一变就要重判。 |
| 金钱与给予：财务边界与付出感改写 | 先用「金钱显化的三条底层逻辑」定位这次到底在争哪一层，再在纯 AA／日常 AA + 年底共同账户／三抽屉里选一种并落实**知情权优先于处理权**；同时用「做这件事本身是否让我快乐」把「付出」改写成「给予」，按给予三原则执行。 |
| 冲突处理协议：三类分流、二八原则与非暴力沟通 | 把「我该怎么跟他开口」落成一份当场能照着念的稿子——先给这场冲突定性（底线／重大问题／日常琐事）再选策略，用 80/20 压住指责面，走四步（说事实→说感受→说缘由或询问→提需求）；判据是「稿子里第 1 步的每句话都能被摄像头录下来，且第 4 步的每条需求都能被验证做了还是没做」。 |
| 长期关系经营：加法关系、仪式感与三大错误努力方向 | 长期关系按加法经营而非减法维持——每日 30 分钟固定共处（说废话 > 解题、无聊事 > 家务、身体互动每天要有）＋一份通过「非必要非功能性 / 交换各自稀缺资源 / 频率上限」三道校验的仪式感清单；**一旦「自我牺牲」与「无条件支持」两条同时成立，立即停止加大投入，转 boundary-three-kinds 或 crisis-navigation，不得顺势建议再努力一点。** |
| 控制型关系与家暴：识别与跳出 | 出现动手、性强迫、经济克扣、贬低或社交切断任一信号，立即停止全部关系分析与沟通／挽救／对质类建议，交付「当下安全判断 + 已确认信号表 + 安全动作清单 + 停止清单」；完成判据是用户能说出一个今晚可执行的安全动作、一个可联系的人、一个求助渠道。 |
| 关系危机：日久生倦、出轨、恐婚与体面分手 | 危机发生后先过安全闸门，再按「暂停 → 梳理 → 分流」产出书面决定；凡以「他会更爱我 / 他会改」为主语的行动判为不可执行，退回改写成以「我」开头。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
